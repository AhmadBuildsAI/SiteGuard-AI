# Evaluation

For object detection (YOLO): mAP@50, mAP@50:95, Precision, Recall.
For safety rules: Precision, Recall, F1 on a human-labeled test set.
For VLM: structured-output validity, human-review agreement rate.

A production system would need a labeled construction-site dataset
(e.g., from Kaggle: "Hard Hat Workers" or "SH17" PPE dataset).
